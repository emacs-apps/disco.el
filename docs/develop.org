* Design notes

Root and room refresh use async requests.  HTTP is ~plz~ with
optional in-process serialization.  REST applies global and
bucket/route cooldown plus bounded 429 retries.

Gateway follows HELLO, heartbeat, identify, and resume.  Dispatch
mutates channel, guild, and thread structure.  Optional
~compress=zlib-stream~ uses a per-connection shared stream context.
Reconnect uses exponential backoff with jitter; ~INVALID_SESSION~
uses a randomized delay window.

Guild directories defer passive EWOC mutations while hidden, then
coalesce dirty channel IDs when redisplayed.  Room EWOC keeps
message-node indexes; reaction and poll-vote events patch rows
locally, while create, update, and delete rerender fully.

READY channel snapshots are reused.  Missing latest-message previews
hydrate through Gateway opcode 34 (~LAST_MESSAGES~).  Identify can
include ~PASSIVE_GUILD_UPDATE_V2~ so activity can refresh from
passive unread deltas.

Shared presentation contracts are documented in Appkit's integrator guide,
not duplicated here.  The ~discord-markdown~ codec is itself the provider
extension boundary:

1. A bounded lexical pass marks inline/fenced code zones.
2. Discord escapes, provider tokens, spoilers, underline, subtitles, ~>>>~
   quotes, suppressed links, and the documented block subset are shielded
   outside those zones.
3. Appkit's low-level dual-grammar Tree-sitter backend adapts the remaining
   Markdown structure.
4. Discord objects are restored as independent immutable occurrences.

Parsing never activates a major mode, Font Lock, language hooks, or grammar
installation.  Generic Appkit codec registration already permits this complete
provider parser/printer pair; no provider hooks were added to Appkit.

Room composition defaults to ~discord-markdown~.  The provider printer retains
escaped mentions and provider wire forms.  Long-message split mode partitions
the captured Document and reprints each chunk rather than slicing Markdown
source.  Attachment spoiler state remains in its attachment side channel.
