#+options: toc:nil num:nil

* What it is

~disco.el~ is an Emacs Discord client.  It uses a telega-style root
and room flow, an ement-style split between API, state, and buffers,
and Appkit for views, composers, and media.

* Start

Set a token, then open the root:

#+begin_src sh
export DISCO_TOKEN=...
#+end_src

#+begin_src emacs-lisp
(require 'disco)
;; or override in-session:
;; M-x disco-set-token
#+end_src

~M-x disco~ opens ~*disco*~.  ~RET~ opens a guild directory or room.

Requires Emacs 27.1, ~plz~, ~websocket~, and Appkit 0.2.15.

Keys, threads, attachments, and options are in the
[[file:docs/user.org][user guide]].  Layouts, file map, and design
notes are in [[file:docs/develop.org][docs/develop.org]].
